# Project 404

Vision AI를 활용해 얼굴과 손의 움직임을 인식하고 게임플레이에 연동한 1인칭 호러 게임입니다.

## 프로젝트 개요

* **개발 기간**: 2026.07 ~ 2026.08
* **개발 인원**: 4인
* **담당 역할**: 유일한 프로그래머로 클라이언트 프로그래밍 전담
* **개발 환경**: Unity · C#
* **주요 기술**: MediaPipe · Vision AI · Gemini
* **형상 관리**: GitHub

## 주요 기능

* 카메라 기반 얼굴 및 손 움직임 인식
* Vision AI 인식 데이터를 게임플레이에 연동
* 플레이어 움직임에 따른 게임 내 상호작용
* 얼굴·손 인식 데이터 좌표 변환
* 손 인식 데이터 Z축 보정
* 상호작용 인터페이스 기반 기능 구현

## 주요 구현

### 1. MediaPipe 데이터와 Unity 게임 로직 연결

MediaPipe에서 전달되는 인식 데이터는 외부 콜백을 통해 전달되고, Unity의 게임 로직은 메인 스레드에서 실행됩니다.

이를 연결하기 위해 `MediaPipeIntegrationBridge`를 구현했습니다.

```text
MediaPipe
   ↓
외부 콜백
   ↓
MediaPipeIntegrationBridge
   ↓
공유 데이터
   ↓
Unity Update()
   ↓
VisionTrackingManager
   ↓
Game Logic
```

외부 콜백에서 전달받은 데이터를 공유 영역에 저장하고 `lock`을 활용해 공유 데이터에 대한 접근을 제어했습니다.

Unity의 `Update()`에서 데이터를 읽어 게임 시스템으로 전달하는 구조로 구성했습니다.

### 2. 얼굴·손 인식 데이터 처리

외부에서 전달되는 인식 데이터를 게임에서 사용할 수 있도록 좌표를 변환하고, 손 인식 데이터의 Z축 값을 보정하는 처리를 구현했습니다.

이를 통해 Vision AI에서 생성된 데이터를 Unity의 게임플레이 좌표계에서 사용할 수 있도록 연결했습니다.

### 3. 인터페이스 기반 상호작용 구조

게임 내 다양한 상호작용 객체가 동일한 방식으로 처리될 수 있도록 `IInteractable` 인터페이스를 정의했습니다.

```csharp
public interface IInteractable
{
    void OnFocusEnter();
    void OnFocusExit();
    void OnReadyStateReached();
    void OnInteract();
    void OnLean();
}
```

공통 인터페이스를 통해 상호작용 객체별 구현을 분리했습니다.

## AI 활용

개발 과정에서 Gemini를 활용해 코드 구현과 문제 해결을 진행했습니다.

초기에는 문제 상황과 필요한 기능만 전달해 코드를 생성했지만, 기존 프로젝트의 클래스 책임과 맞지 않는 코드가 제안되는 경우가 있었습니다.

이후에는 현재 클래스의 역할과 호출 관계, 데이터 흐름 및 구현 제약조건을 함께 전달하고 생성된 코드를 기존 구조와 비교했습니다.

AI가 생성한 코드를 실제 프로젝트에 적용한 뒤 실행 결과와 기존 코드의 구조를 확인하고 필요한 부분을 다시 수정하는 방식으로 활용했습니다.

### State Ledger

장시간 AI와 함께 개발하면서 이전 대화에서 결정한 구조와 작업 내용을 놓치는 문제가 발생했습니다.

이를 보완하기 위해 작업 종료 시 변경된 클래스, 완료된 작업, 진행 중인 작업을 `State Ledger`로 정리하고 다음 작업에 다시 제공했습니다.

이를 통해 AI가 현재 프로젝트의 상태를 기준으로 작업을 이어갈 수 있도록 개발 맥락을 관리했습니다.
